# תוסף Chrome: מכסות השימוש בקלוד

נוסף ב-17.11.2026, "דרך 3" במעקב אחרי השימוש בקלוד.

## מה הוא עושה

כל רבע שעה התוסף קורא מ-claude.ai כמה אחוז מחלון חמש השעות ומהמכסה השבועית כבר נוצלו, ומתי כל אחד מתאפס. את שני האחוזים, שני זמני האיפוס ומייל החשבון הוא שולח לאנקורה:

```
https://www.ankora.co.il/api/claude-limits
```

הוא לא קורא שיחות, פרומטים או קבצים, ולא שולח שום דבר אחר.

המכסה שייכת לחשבון, לא למקום שבו עובדים. לכן המספר הזה מכסה דפדפן, טלפון, אפליקציה ו-Claude Code. את זה הטלמטריה לא נותנת בתוכנית צוות.

## מגבלות

- הנתון מגיע מממשק פנימי של claude.ai, אותו ממשק שמאחורי Settings > Usage. הממשק לא מתועד ויכול להשתנות. אם זה קורה, הקריאות נעצרות, ובמסך "שימוש בקלוד" רואים שהקריאה האחרונה של העובד מתיישנת.
- התוסף עובד רק בפרופיל Chrome של העבודה. אם עובד נכנס ל-claude.ai בפרופיל אחר או בדפדפן אחר, הקריאה לא תגיע. מספיק שהדפדפן פתוח עם הפרופיל של העבודה: המכסה היא של החשבון, גם כשעובדים בטלפון.
- הסוד מגיע לתוסף דרך מדיניות של Chrome, ומי שמנהל את המחשב יכול לקרוא אותו. מי שמחזיק בסוד יכול לשלוח קריאה מזויפת, אבל קריאה היא רק שני אחוזים, והכתובת מוגבלת בקצב. אם הסוד דולף, מחליפים אותו בשני המקומות.

## מי מכניס את הסוד

- **אדם, לא Claude.** Claude לא מקליד סודות לשדות בדפדפן: לא בשדה המדיניות בקונסולת Workspace, ולא בדף ה-Options של התוסף.
- **הסוד לא נכתב בשום מקום** חוץ מ-Vercel, מהמדיניות ב-Workspace ומהכספת של אריאל: לא בצ'אט, לא בדיווח, לא בקובץ ולא בריפו.
- **סוד שהופיע בתמליל של סשן נחשב דלוף.** הסוד הראשון נוצר בסשן של Claude, ולכן מחליפים אותו לפני שלב 4:
  1. אריאל מריץ במסוף `openssl rand -hex 32 | pbcopy` ושומר את הערך בכספת.
  2. אריאל מעדכן את `CLAUDE_LIMITS_SECRET` ב-Vercel.
  3. מפעילים Redeploy לפרודקשן ובודקים שבקשה בלי הרשאה מחזירה 401.
  4. אריאל מדביק את אותו ערך במדיניות ב-Workspace, בשלב 4.

## התקנה לכל העובדים, פעם אחת

1. **סוד ב-Vercel.** יוצרים ערך אקראי בפקודה `openssl rand -hex 32`. מוסיפים משתנה סביבה בשם `CLAUDE_LIMITS_SECRET`, ב-Production בלבד, מסוג Sensitive. אחר כך מפעילים Redeploy לפרודקשן. לבדיקה: בקשת POST לכתובת בלי כותרת הרשאה צריכה להחזיר 401. אם חוזר 503, הסוד עדיין לא נקלט.

2. **אריזה.** בתיקייה הזו מריצים:
   ```
   zip -r claude-limits-extension.zip manifest.json managed_schema.json background.js options.html options.js
   ```

3. **פרסום בחנות.** ב-Chrome Web Store Developer Dashboard, עם חשבון ankora.co.il, מעלים את קובץ ה-zip. רישום חד פעמי כמפתח עולה 5 דולר. אחרי האישור, רושמים את מזהה התוסף, מחרוזת של 32 אותיות.

   ב-Visibility נבחר Unlisted. תחת Private הופיעו רק Trusted Testers וקבוצה אחת, בלי אפשרות לכל הדומיין, גם אחרי שהפרסום הארגוני אושר. Unlisted מספיק: מי שמתקין את התוסף בלי המדיניות של Workspace לא מקבל את הסוד, והשרת דוחה כל בקשה בלעדיו. בקוד התוסף אין שום סוד. אם בעתיד האפשרות לכל הדומיין תופיע תחת Private, אפשר לעבור אליה, והמעבר ידרוש בדיקה חוזרת של Google.

   חנות התוספים חוסמת תוספים, כולל Claude in Chrome, בכל הדפים שלה. לכן כל פעולה ב-Developer Dashboard נעשית ידנית.

4. **התקנה בכוח.** בקונסולת Google Workspace: Devices > Chrome > Apps & extensions > Users & browsers. בוחרים את היחידה Ankora, לוחצים Add app ואז Add the Chrome app or extension by ID, ומדביקים את המזהה. אפשר להוסיף את התוסף רק אחרי שהוא מפורסם. לפני כן הקונסולה מחזירה "Failed to add app". ב-Installation policy בוחרים Force install. בשדה Policy for extensions מדביקים:
   ```json
   {
     "secret": { "Value": "<הסוד משלב 1>" },
     "endpoint": { "Value": "https://www.ankora.co.il/api/claude-limits" }
   }
   ```
   את הסוד מדביק אדם (ראו "מי מכניס את הסוד"). שומרים. מדיניות משתמשים כבר מוחלת על כל מי שמחובר ל-Chrome עם חשבון ankora.co.il. ההגדרה הרלוונטית היא Apply all user policies when users sign in to Chrome.

5. **בדיקה.** תוך כרבע שעה, במסך "שימוש בקלוד", בחלק "חלון חמש השעות", מופיע ליד כל עובד פס עם האחוז מהחלון הנוכחי, הזמן עד האיפוס והאחוז השבועי. כל עוד לא הגיעה אף קריאה, מעל הרשימה מופיעה ההודעה "עוד לא הגיעה מדידה מהתוסף בדפדפן". עובד שיש לו פעילות אבל אין לו קריאה יופיע בפעולות, בשורה "לבדוק את התוסף אצל...". מדידה מכתובת שאין לה עובד באנקורה, למשל כינוי של חשבון עבודה, מופיעה בפעולות כ"מדידת מכסה בלי עובד" ובחלק "מקורות".

## עדכון גרסה

מעלים את מספר הגרסה ב-`manifest.json`, אורזים מחדש ומעלים לאותו פריט ב-Developer Dashboard. Chrome מעדכן לבד.

## בדיקה ידנית בלי הארגון

ב-`chrome://extensions` מדליקים Developer mode, לוחצים Load unpacked ובוחרים את התיקייה הזו. ב-Options ממלאים את הכתובת ואת הסוד, ולוחצים "שמירה ובדיקה". מתחת לכפתור מופיעה תוצאת הקריאה האחרונה.
